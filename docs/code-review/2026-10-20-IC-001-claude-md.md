Дата: 2026-10-20 · Изменение: только документация (код не менялся).

## Что проверено

| Ось | Результат |
|---|---|
| Безопасность | Новый граф не ослабляет анонимность: `realtime` больше не знает авторов и фаз, адресатов считает модуль, у которого есть политика (`*/model/policy.py`). `my_vote` собирает `vote`, идея не читает чужие голоса. Ошибка `invalid_contest` не раскрывает данных. |
| Структура | Пути и имена заменены на существующие (`ContestSchedule.phase_at`, `result/model/ranking.py`, `*/model/policy.py`, `FrozenClock`). Владельцы таблиц §7.1 названы модулями. |
| Архитектура | Граф §4.2 без циклов: `common ← user ← auth`; `user, contest ← idea ← vote ← result`; `contest, idea, vote ← reminder`; `notification`, `realtime` — листья. Решения, меняющие архитектуру, помечены «предложено, ждёт согласования». |
| Корректность | Каждое решение — строка в §17 с причиной и связью с ТЗ. |

## Найдено и исправлено

1. В первой редакции маршрут списка идей оставался в `idea.controller`, но тогда ему понадобился бы `vote.service` — ребро `idea → vote` и цикл. Маршрут перенесён в `vote.controller`.
2. Пример имени функции в §6.2 ссылался на несуществующую `compute_phase` — заменён на `rank_ideas`.
