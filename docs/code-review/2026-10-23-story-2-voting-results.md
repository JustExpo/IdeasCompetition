## Безопасность
- Порядок 401 → 404 → 403 → 409 проверен тестами `test_checks_order_401_404_403_409`, `test_vote_in_submission_hides_foreign_idea`: в приёме чужая идея невидима (404), несуществующая идея неотличима от чужой.
- Организатор голосовать не может (403 `organizer_cannot_participate`), за свою идею — 403 `own_idea_vote` (раскрывает авторство только самому автору).
- Итоги: сотрудник до финала получает 403, организатор — места без авторов; схемы `ResultItem`/`FinalResultItem` и `DashboardResponse` с `extra="forbid"`, авторов в экране организатора нет и после финала. Тесты сверяют отсутствие имён в тексте ответа.
- Кто за что голосовал не раскрывается никому: наружу отдаётся только `my_vote` самому голосующему и агрегаты.
- SQL — только SQLAlchemy с параметрами; в логи ничего нового не пишется.
