# Самопроверка: стори 1 (IC-010–IC-012) — конкурсы, подача и правка идей, список по фазам

Дата: 2026-10-22. Проверено по §6.5 CLAUDE.md.

## Безопасность
- Порядок проверок 401 → 404 → 403 → 409: чужая и несуществующая идея неразличимы (404 `idea_not_found`), в том числе при неверной версии и закрытом приёме (тест `test_someone_elses_idea_looks_like_a_missing_one`).
- Анонимность: в фазе голосования схема `IdeaForVoting` без автора и времени подачи, `extra="forbid"`; тесты сверяют точный набор ключей и отсутствие имён авторов в тексте ответа. Порядок — по UUID, не по времени подачи.
- В подаче организатору чужие идеи не отдаются; организатор подавать и править не может (403).
- Ввод: NFC, trim, запрет управляющих и невидимых символов, длины из констант модели; одиночные суррогаты отклоняются (422); тело запроса не эхом в ошибке.
- SQL только через SQLAlchemy с параметрами; тексты идей не пишутся в логи (маскирование из IC-003).

## Структура
- Файлы по §4.4: модели в `model`, SQL в `dao`, сценарии в `service`, схемы и маршруты в `controller`; импорты проверены `lint-imports` (17 контрактов kept).
- Список идей — в `vote.controller` (граф §4.2), `can_view_authors` перенесён в `contest.model`.

## Архитектура
- Транзакции через `run_in_transaction`, `now` читается после `contest FOR SHARE` и `idea FOR UPDATE` (Р4, Р6); события не публикуются (IC-024).
- Миграции `0003`, `0004` — expand; `alembic check` без расхождений; цикл upgrade → downgrade -1 → upgrade пройден. `winner_idea_id` без FK (цикл с `ideas`), записано в §17.

## Корректность
- Границы `d−1µs / d / d+1µs` для подачи, правки и списка; пустое, максимум и максимум+1 для текстов; повтор запроса; гонка двух вкладок при правке (ровно один 200 и один 409 `stale_version`).
- Найдено и исправлено: дедлайн отдавался со смещением клиента (теперь UTC, регрессионный тест); тест списка искал имена в названиях идей (проверка переведена на имена авторов).
- Известные ограничения: лимиты 20/1000 мягкие при параллельных вставках (§7.2).
