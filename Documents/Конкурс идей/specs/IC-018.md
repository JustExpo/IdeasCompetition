# IC-018 Добавить голосование, удаление идеи и результаты на странице конкурса

| Поле | Значение |
|---|---|
| Этап | Э4. Frontend MVP (точка MVP) |
| Приоритет | Высокий |
| MVP | Да |
| Статус | см. [TODO.md](../TODO.md) — единственный источник статусов |
| Ожидаемый результат | Список идей без авторов с голосом и отзывом; удаление своей идеи с подтверждением; таблица результатов |

## Цель и ценность

П4–П6, П8, П11, Ф4 в браузере.

## Контекст

Данные и права приходят из API; frontend не дублирует правила фаз.

## Что входит в задачу

- `features/voting`: голос и отзыв по `my_vote`, своя идея без кнопки
- Удаление идеи с подтверждением и предупреждением о голосах
- `features/results`: места, авторы после финала, «идей нет»

## За пределами задачи

- Обновление у других пользователей без перезагрузки (IC-025)

## Зависимости

- Зависит от: [IC-017 Добавить страницу конкурса с подачей и правкой идей](IC-017.md), [IC-014 Реализовать результаты и API экрана организатора](IC-014.md)
- Блокирует: [IC-019](IC-019.md)

## Функциональные требования

- 404 на голос → «Идея удалена автором» и идея убирается из списка
- Все идеи свои → «Голосовать не за что»

## Технические ограничения и затрагиваемые компоненты

- `features/voting`, `features/results`
- Общие правила: CLAUDE.md §4 (модули и слои), §6 (стиль), §14 (Definition of Done).

## Пограничные случаи и обработка ошибок

- Голос после дедлайна → 409 и перечитывание
- Удаление в финале недоступно
