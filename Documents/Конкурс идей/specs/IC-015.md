## Цель и ценность

Frontend с первого экрана работает на сгенерированных типах, под CSP и с одинаковой обработкой ошибок (О1, О3, §8.1).

## Контекст

Генератор `npm create vite` записывается в §15 и README (С7).

## Что входит в задачу

- `app.cli export-openapi` (без БД, стабильная сортировка), `make contract`, `frontend/openapi.json`, `schema.gen.ts`
- Каркас frontend: strict TS, ESLint, Prettier, dependency-cruiser, Vitest + Testing Library + MSW, react-router, react-query, openapi-fetch, Vite-прокси `/api` + ws
- `shared/lib/serverTime.ts` и хук перечитывания на дедлайне и при `visibilitychange`
- Единый разбор ошибок: `code` → русский текст, ветки 401/403/404/409/422/429/503/500, пустые состояния
- Стадия node в Dockerfile, статика + fallback на `index.html`, CSP §9.3; frontend-шаги в CI

## Принятые решения по результатам обсуждения

Решения реализации (2026-10-22; координатор по поручению владельца, на согласование в MR). Спецификация с владельцем отдельно не обсуждалась, поэтому ниже — принятые при реализации решения, а не согласованные требования.

- Каркас написан вручную, генератор `npm create vite` не использовался (интерактивный, добавил бы лишние файлы); чужого кода и шаблонов нет.
- Версии закреплены точно в `package.json` и `package-lock.json`: React 18.3, react-router-dom 7, @tanstack/react-query 5, openapi-fetch, Vite 8 и Vitest 5 (более ранние Vitest/react-router давали `npm audit` с уязвимостями уровня critical/moderate), TypeScript 5.9 (typescript-eslint не принимает 6+/7), ESLint 9 (с ESLint 10 не совпадают peer-зависимости плагинов).
- `app.cli export-openapi --output PATH` собирает приложение из заглушечных настроек через `Settings.model_validate` (окружение не читается, БД не подключается); JSON сортируется по ключам, поэтому `make contract` идемпотентен, а `make test-contract` падает на любом дрейфе `frontend/openapi.json` и `schema.gen.ts`.
- Раздача SPA — `app/core/spa.py`, подключается в `create_app(spa_dir=…)` последним маршрутом; каталог `frontend/dist` лаунчер находит сам (`SPA_DIR`), в образе это `/app/frontend/dist`. Файл внутри каталога отдаётся как есть (`assets/*` — `immutable`, остальное — `no-cache`), любой другой путь вне `/api` — `index.html`, путь `/api/…` — 404 problem+json для любого метода, небезопасный метод на пути SPA — 405. Выход за каталог (`..`, символические ссылки) закрыт.
- CSP из CLAUDE.md §9.3 ставится прослойкой `RequestContextMiddleware` на все ответы (а не только на HTML): ответы ошибок и API получают те же заголовки безопасности.
- Типы конкурсов: пока `/api/contests` нет в OpenAPI (IC-010 не вошёл в `main`), форма ответа описана временным `src/api/pendingContracts.ts` по CLAUDE.md §8.2. Тест `contract.test.ts` упадёт, когда маршруты появятся в `openapi.json`: тогда выполнить `make contract`, удалить временный файл и `PendingPaths`.
- Серверные часы (`shared/lib/serverTime.ts`) запоминают смещение по `server_time`; хук `useDeadlineRefetch` ждёт отрезками ≤ 30 с и сверяется с серверными часами, а при возвращении на вкладку (`visibilitychange`) проверяет дедлайн сразу. Источник `server_time` появится с `GET /api/contests/{id}` (IC-010/IC-017); до этого часы берут время компьютера.
- Единый разбор ошибок — `src/api/errors.ts`: `code` → русский текст (неизвестный код → «Не удалось выполнить действие. Код запроса: …»), ветки по статусу (`ErrorKind`), поля форм из `errors[]` и из кодов, `Retry-After` в тексте для 429/503. Повторы запросов чтения: ≤ 2, только сбои сети и 5xx (§8.3). 401 `not_authenticated` в любом запросе сбрасывает сессию и уводит на вход с возвратом на исходный адрес (адрес возврата проверяется: только путь своего сайта).
- Границы слоёв (§4.2) проверяют dependency-cruiser (`shared` ниже `api`; `features` не импортируют друг друга, `pages` и `app`) и ESLint (`fetch`/`WebSocket` — только `src/api`, `Date.now()`/`new Date()` без аргументов — только `serverTime.ts`).
- CI: job `frontend` (prettier, eslint, tsc, depcruise, vitest, build, `npm audit --audit-level=high`), job `contract` (`make test-contract`), в job `docker` — проверка, что контейнер отдаёт `/` и `/contests/1` с CSP и `/api/unknown` как 404 problem+json.
